2. أخطاء برمجية حرجة (Critical Bugs) - يجب إصلاحها فوراً
--------------------------------------------------------------------

أ) خطأ توقف جافاسكريبت بالكامل (ReferenceError):
- الملف: script.js (السطر 37)
- المشكلة: كتابة "math" بحرف صغير (math.floor) بدلاً من Math بحرف كبير.
  لغة JavaScript حساسة لحالة الأحرف، لذا هذا الخطأ يمنع تنفيذ الكود وحساب العمر.
- التصحيح:
  // قبل:
  document.getElementById("agevar").innerHTML = math.floor(years);

  // بعد:
  document.getElementById("agevar").innerHTML = Math.floor(years);


ب) روابط مشاريع معكوسة وأخطاء نسخ ولصق (Copy-Paste Errors):
- الملف: index.html (الأسطر 114 - 141)
- المشاكل:
  1. مشروع WeatherHQ: زر المعاينة الحية وزر الـ Repo يشيران لـ ToDoList.
  2. مشروع To Do List: زر المعاينة الحية وزر الـ Repo يشيران لـ WeatherHQ.
  3. كلمة "Caffine Cove" يُفضل تصحيحها إملائياً إلى "Caffeine Cove".


ج) استخدام وسوم HTML غير قياسية (Invalid HTML Elements):
- الملف: index.html (الأسطر 90 - 140)
- المشكلة: استخدام وسم غير معروف في HTML5 باسم <BTN> وبداخله وسم الرابط <a>.
- التصحيح: استبدال <BTN> إما بـ <div> أو إزالته والاعتماد على تنسيق عنصر الرابط <a> مباشرة بكلاس مخصص.


د) استخدام دالة CSS غير مدعومة (Invalid CSS Function):
- الملف: style.css (الأسطر 147 - 151)
- المشكلة: استخدام ()font-size: if داخل الـ CSS، وهي خاصية غير قياسية وغير مدعومة في المتصفحات وتتسبب في فشل تطبيق حجم الخط.
- التصحيح: استخدام clamp() أو Media Queries:
  font-size: clamp(18px, 2.5vw, 36px);

3. التجاوب مع مختلف الشاشات (Responsiveness & Mobile Layout)
--------------------------------------------------------------------

الموقع حالياً يواجه مشكلة التمرير الأفقي (Horizontal Overflow) وتكسر التصميم على الهواتف والأجهزة اللوحية للأسباب التالية:

1. قياسات ثابتة وكبيرة جداً بالبكسل (px):
   - nav يحتوي على padding: 0 234px مما يكسر الهيدر على الشاشات الصغيرة.
   - صور المشاريع One-ProjectImg محددة بـ width: 826px ثابتة.
   - أزرار المشاريع One-ProjectBTN1 بعرض 405px ثابت لكل زر.
   - كارت البريد الإلكتروني Email بعرض 1301px و 966px.
   - الحل: استخدام Max-Width ونسب مئوية مرنة:
     width: 100%;
     max-width: 800px;

2. أيقونات التواصل الاجتماعي:
   - 5 أيقونات بعرض 210px ومسافات 60px تطلب مساحة تتجاوز 1300px.
   - الحل: جعل الأيقونات مرنة واستخدام CSS Grid أو Flexbox مع flex-wrap لتتحول لسطرين على الموبايل.

3. إخفاء شريط التمرير (Hidden Scrollbar):
   - كود إخفاء شريط التمرير في html::-webkit-scrollbar يقلل من سهولة الاستخدام للمتصفحين على أجهزة الكمبيوتر.

4. تجربة المستخدم والتصميم وسهولة الوصول (UI/UX & Accessibility)
--------------------------------------------------------------------

1. الخط المائل (Italic):
   - استخدام font-style: italic في كافة النصوص والعناوين والفقرات يجهد العين ويقلل مقروئية النصوص الطويلة.
   - النصيحة: حصر الـ Italic على الكلمات البارزة أو العناوين فقط، وإبقاء النصوص التوضيحية عادية (normal).

2. إمكانية تكبير الشاشة (Viewport Zoom):
   - في وسوم meta بملف index.html، تم استخدام user-scalable=no مما يمنع ضعاف البصر من تكبير الصفحة.
   - النصيحة: استبدالها بـ:
     <meta name="viewport" content="width=device-width, initial-scale=1.0">

3. النصوص البديلة للصور (Alt Attributes):
   - كتابة وصف دقيق داخل alt="..." لصور المشاريع والشعار لتحسين ظهور الموقع في محركات البحث (SEO) ودعم قارئات الشاشة.

4. حقل البريد الإلكتروني (Email Input):
   - استخدام خاصية readonly بدلاً من disabled لتسهيل تحديد النص ونسخه يدوياً من قِبل الزائر.

5. زر النسخ:
   - إضافة نص تفاعلي (Tooltip أو إشعار Toast) يوضح "تم النسخ بنجاح!" لتحسين التغذية الراجعة للمستخدم.
